# 三套内置自动化模板

这些模板用于创建自动化，不代表安装 Skill 后会自动运行。创建或更新任务时：

- 新建后保持暂停状态。
- 只保存配置，不要自动运行，不要立即测试。
- 用户手动启用后，自动化才能按计划执行。
- 把模板中的 `<知识库绝对路径>` 替换为真实路径。

## 1. 资料沉淀队列

默认状态：`PAUSED`

建议频率：选择低使用时段，避开用户高频使用 Codex 的时间；例如每周一次或按资料投放节奏设置。

工作目录：`<知识库绝对路径>`

```text
使用 $local-materials-to-course-kb 处理本地知识库资料队列。

先读 README.md、AGENTS.md、index.md，以及
知识库/课程知识库/00_任务状态/当前批次状态.md。

先盘点，不要扫描全库：
- 素材/待整理/TBD
- 素材/待整理/待复核/课程资料

如果存在未完成批次，先恢复它；否则从 TBD 选择一个主题一致、规模合理的批次。
每次最多处理一个批次。Done 只读，不作为新资料来源。不得一轮清空 TBD，
也不得因为还有资料就连续扩大上下文。

知识正文写入对应分类的 01_知识主题/；01_知识主文档.md 只更新主题导航。
完成审核、去重、正式写入、分类索引、总索引和结构验证后，才把源资料移到
素材/待整理/Done/YYYY-MM-DD_批次名/。

如遇到上下文、OCR、图片、资料歧义或核验障碍，保留当前批次并更新状态文件后停止。
不要自动扩大处理范围。
```

## 2. 本地知识库每周体检

默认状态：`PAUSED`

建议频率：每周一上午。

工作目录：`<知识库绝对路径>`

```text
对当前本地知识库做只读体检，不修复、不移动、不删除文件。

先读 README.md、AGENTS.md、index.md，再按需查看相关页面。检查：
1. 素材/待整理/TBD 的积压数量；
2. 素材/待整理/待复核/课程资料 的状态和积压；
3. 课程分类入口页与 01_知识主题/ 的链接；
4. 图片链接、孤立页面、重复主题、没有来源的结论；
5. 进行中项目和当前批次是否长期未更新；
6. 是否仍残留旧 media/ 或 98_音视频处理工作区 路径。

检查断链、重复、孤岛、未整理、待确认、过期和索引覆盖。
固定输出：
- 健康分：0-100，并说明主要扣分原因；
- 本次发现的问题；
- 最优先处理的 3 件事；
- 建议下一步。
本次只读，不要自动修复，也不要触发资料沉淀。
```

## 3. 每周创作复盘

默认状态：`PAUSED`

建议频率：每周一上午，或在稳定创作日之后。

工作目录：`<知识库绝对路径>`

```text
只复盘 素材/待整理/待复核/创作复盘 中新增且材料完整的创作案例。

每个案例应尽量包含 AI 初稿、人工修改意见和最终稿。若材料不完整，只列入待补充清单，
不要猜测修改原因。

对可复盘案例提炼：
- 初稿主要问题；
- 人工修改背后的判断；
- 可复用的表达规律；
- 容易过度拟合的个例；
- 下次可直接使用的检查清单。

区分稳定规律、待观察和待确认；每条判断注明来源文件或复盘链接。

允许写入仅限：
- reviews/YYYY-MM-DD-创作复盘.md
- wiki/写作风格.md
- wiki/脚本结构.md
- wiki/标题方法.md
- wiki/AI协作规则.md
- index.md
- log.md

不要读取课程资料待复核区，不要移动、删除或修改原始创作材料。
```
