# Local Materials To Course KB

把本地资料沉淀成课程知识库、案例库、SOP 和审核记录的 Codex skill。

这个项目不是为了再造一个「文档转 Markdown」工具。它解决的是另一件更常见的事：资料越攒越多，收藏夹越来越满，视频课、PDF、PPT、会议转写、学习笔记一层套一层，最后真正能拿来培训新人、写 SOP、做课程的内容，反而没沉淀下来。

如果你也经常这样：

- 看到好资料先存起来，想着「以后整理」；
- 做培训时发现素材很多，但能直接讲的案例很少；
- 想把经验变成 SOP，却总卡在分类、去重、审核和重写；
- 视频课转写了一堆文档，最后不知道该放哪；
- 半夜还在等 Codex 额度恢复，想着「醒了就顺手再跑一批」，这事听起来勤奋，其实有点狼狈。

那这个 skill 大概率能帮上忙。

## 它做什么

`local-materials-to-course-kb` 会把本地资料按课程编辑的方式处理：

1. 先看资料要服务什么课程、什么岗位、什么业务场景。
2. 再判断资料数量、复杂度、信息密度和分类跨度。
3. 一次只选一个合适批次，不把所有资料硬塞进上下文。
4. 从资料里提炼知识点、案例、图片、SOP、话术和模板。
5. 把过时、证据不足、高风险、隐私敏感的内容拦下来，写进审核记录。
6. 最后更新知识库索引、分类文档、案例库和模板库。

它的重点是「可复用的课程资产」，不是漂亮摘要。

## 适合谁

- 培训负责人、讲师、内训师；
- 做 SOP、流程、项目复盘的人；
- 囤了很多 PDF、Word、PPT、视频转写稿的人；
- 做 Amazon 运营、电商培训、选品调研、广告推广的人；
- 想搭建个人知识库，但不想每天手工搬文件、改目录、补索引的人。

## 核心设计

### 1. 用 `TBD` 和 `Done` 管住资料流

初始化后会创建：

```text
~/Desktop/AI工作台/06_培训教程与分享资料/本地资料转课程知识库/media/TBD
~/Desktop/AI工作台/06_培训教程与分享资料/本地资料转课程知识库/media/Done
```

你只需要把待沉淀资料放进 `TBD`。

Codex 每次运行时会从 `TBD` 中挑一个合适批次，移动到当前批次文件夹里处理。处理完后，源资料会移动到 `Done`，空的当前批次文件夹会删除。后续运行不会再碰 `Done`，除非你明确要求重新处理。

### 2. 质量优先，不追求一次吃完

这个 skill 默认不鼓励一次处理十几二十份资料。资料多时，它会先做盘点，再按主题、复杂度和信息密度拆批。

默认建议：

| 资料情况 | 建议每批深度处理量 |
|---|---:|
| 同主题、纯文字 Word/PDF | 6-10 份 |
| 主题混杂、分类不确定 | 3-5 份 |
| PPT、截图多、带演讲者备注 | 2-4 份 |
| 视频转写包 | 1-3 个课程包 |
| 平台规则、费用、政策、账号安全 | 2-4 份 |
| 高价值课程沉淀 | 4-6 份 |

### 3. 可以配合 Codex 自动化

你可以设置一个 Codex 自动化，让它每隔一段时间检查 `TBD`。如果里面还有资料，它就处理一批；如果额度、上下文或文件复杂度卡住，它会写状态文件，下一轮继续。

这比一直守在电脑前等额度恢复体面一点。至少人可以睡觉，资料慢慢排队。

## 快速开始

1. 把 `skills/local-materials-to-course-kb` 复制到你的 Codex skill 目录。
2. 重启 Codex，让它重新读取 skill。
3. 让 Codex 运行：

```text
使用 local-materials-to-course-kb 初始化课程知识库。
```

4. 初始化后，把资料放进：

```text
~/Desktop/AI工作台/06_培训教程与分享资料/本地资料转课程知识库/media/TBD
```

5. 再对 Codex 说：

```text
使用 local-materials-to-course-kb 继续沉淀 TBD 里的资料。
```

## 和通义听悟配合

如果你要处理视频课、直播回放、会议录音，可以先用通义听悟转写：

[通义听悟](https://tingwu.aliyun.com/home)

使用经验：

- 每天签到通常会送 10 个小时转录时间，具体规则以平台页面为准；
- 单次视频最好不要超过 6 个小时；
- 长视频最好按主题拆开上传，不要把几个不相关主题塞进一个转写文件；
- 如果视频很长，建议拆成 1-3 个主题包再放进 `TBD`；
- 优先导出带时间戳的原文转写稿；
- 如果有导读、关键帧 PPT、自己的学习笔记，也可以放在同一个资料包里。

这个 skill 会把这类资料当成「视频转写包」处理，而不是把一堆 Word/PPT 当成互不相关的文件。
