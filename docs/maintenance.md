# 队列维护与复核收口

## 先盘点

```bash
python3 skills/local-materials-to-course-kb/scripts/queue_inventory.py \
  --vault-root "/你的/个人知识库路径"
```

脚本只读取顶层名称和状态，不打开资料正文。它会统计：

- TBD 待处理项；
- Done 已归档项；
- `待复核/课程资料` 的状态；
- `待复核/创作复盘` 的数量；
- 下一步建议。

机器可读输出：

```bash
python3 skills/local-materials-to-course-kb/scripts/queue_inventory.py \
  --vault-root "/你的/个人知识库路径" --format json
```

## 结构验证

```bash
python3 skills/local-materials-to-course-kb/scripts/verify_course_kb.py \
  --vault-root "/你的/个人知识库路径"
```

它会检查标准目录、任务状态、分类入口、`01_知识主题/`、图片链接、待复核积压和额外分类。

## 课程资料如何复核

入口：

```text
素材/待整理/待复核/课程资料
```

判断标准：

1. 每次只选 1–3 个相关项目；
2. 优先看 `06_待写入知识库内容` 和 `05_审核记录`；
3. 与正式主题页去重；
4. 过时、高风险或证据不足的内容不进正式知识；
5. 写入后同步更新入口导航、分类索引、总索引和审核记录。

通过条件：

- 正文已经进入 `01_知识主题/`；
- `01_知识主文档.md` 有可用入口；
- 索引与审核记录一致；
- 结构验证已运行；
- 状态先改为 `已写入`；只有物理移动到 `Done` 成功后才能改为 `已归档`。

一个复核资料包只有在所有独立资料均已完成、没有遗留 A/B 或其他后续动作，并且正式页、
审核记录、复核文件、相关索引、状态、接力摘要、`index.md` 和 `log.md` 都已同步，
结构检查通过后，才在同一轮任务中移动到：

```text
素材/待整理/Done/<稳定批次名>_已归档
```

只要任一资料仍在复核，就不得整体移动。`Done` 存在同名目标时使用日期、批次子目录或
稳定后缀，绝不覆盖、合并或删除既有归档。移动失败时保留原位和 `已写入` 状态，
记录“归档待重试”、原因和下一步；移动后运行 `verify_course_kb.py` 和
`queue_inventory.py`，确认源路径、目标路径及剩余积压。

移动到 `Done` 是归档，不是删除。未经用户明确要求，不删除待复核材料或归档内容。

## 四项周期维护

- TBD 多时只拆批，并建议低使用时段续跑；一次仍只处理一个批次。
- 课程资料对话式复核由 AI 先总结、用户只判断 A/B 结论；未确认不写入，自动化只恢复现场和提出问题。
- 知识库体检默认只读，固定检查断链、重复、孤岛、未整理、待确认、过期和索引覆盖。
- 创作复盘只看指定创作资料目录，按稳定规律、待观察、待确认管理证据。

## 两阶段只读体检

先由脚本做文件统计和候选定位：

```bash
python3 skills/local-materials-to-course-kb/scripts/kb_health_inventory.py \
  --vault-root "/你的/个人知识库路径" --format json
```

脚本可以在本地解析 Markdown 和计算哈希，但 JSON 只输出计数、问题类型和相对路径，每类候选默认最多 50 项。原始转写目录只统计路径，不读取正文。

第二阶段才由 AI 从每类候选中挑 1–3 个页面判断。不要把脚本扫描到的正文、整个分类或全库文件批量送进模型。
