# 视频资料转课程知识库

先把视频或录音转成文档包，再交给 Skill。原始媒体不是默认输入，除非转写缺失、明显不完整，或用户要求直接检查。

## 推荐资料包

```text
2026-06-XX_广告结构优化课_v1_待沉淀/
├── 原文转写稿.docx
├── 导读.docx
├── 关键帧.pptx
└── 我的学习笔记.md
```

优先级：

1. 带时间戳的原文转写稿；
2. 含关键帧或讲者备注的 PPT；
3. 导读；
4. 用户自己的学习笔记。

工具自动生成的摘要只能作辅助，不能代替原始转写和人工判断。

## 放入队列

把整个主题包放入：

```text
<vault>/素材/待整理/TBD
```

不要把同一课程包拆成互不相关的散件。长视频先按主题拆包，后续分类和追溯都会更清楚。

## 中间产物

课程资料复核区可以保留：

```text
02_转写稿/
03_课程笔记草稿/
04_关键帧候选/
05_审核记录/
06_待写入知识库内容/
```

审核通过后：

- 稳定知识进入 `01_知识主题/`；
- 入口链接进入 `01_知识主文档.md`；
- 图片和案例进入案例库；
- SOP 和话术进入模板库；
- 过时规则、价格、平台入口、账号安全和高风险做法进入审核记录。

视频里“讲得顺”不等于适合写成长期知识，这一步不能省。
