# 视频资料转课程知识库流程

很多课程资料不是从 PDF 开始的，而是从视频、直播、会议录音开始的。

这个项目推荐把视频先转成文档包，再交给 skill 处理。不要一上来就让 Codex 直接读原始视频。

## 推荐工具：通义听悟

入口：

[通义听悟](https://tingwu.aliyun.com/home)

使用经验：

- 每天签到通常会送 10 个小时转录时间，具体规则以平台页面为准；
- 单次视频最好不要超过 6 个小时；
- 长视频建议按主题拆开上传；
- 一个主题一个转写包，后续更容易沉淀成课程模块。

如果一个视频横跨多个主题，比如「选品方法」「广告结构」「团队复盘」混在一起，建议先拆开。拆得越清楚，后面的知识库越干净。

## 推荐导出内容

一个视频转写包可以包含：

```text
2026-06-XX_广告结构优化课_v1_待沉淀/
├── 原文转写稿.docx
├── 导读.docx
├── 关键帧.pptx
└── 我的学习笔记.md
```

优先级如下：

1. `原文转写稿.docx`  
   最重要。最好带时间戳和关键帧。

2. `关键帧.pptx`  
   如果里面有更清楚的图、截图、讲师备注，就一起放进去。

3. `导读.docx`  
   可以帮助快速了解结构，但不要只靠导读沉淀正式知识。

4. `我的学习笔记.md`  
   如果是你自己写的判断、补充、纠错、案例，很有价值。如果只是工具自动总结，就当辅助资料。

## 放进 TBD

把整个文件夹放进：

```text
media/TBD
```

不要拆散成多个孤立文件。一个主题包就是一个资料单元。

Codex 会先判断：

- 哪个文件是主来源；
- 关键帧是否完整；
- PPT 是否需要读取演讲者备注；
- 导读和笔记是不是辅助材料；
- 术语是否需要校准，比如 SKU、ASIN、CPC、Listing、父子变体。

## 输出会是什么

视频包通常会先形成这些中间材料：

```text
02_转写稿/
03_课程笔记草稿/
04_关键帧候选/
05_审核记录/
06_待写入知识库内容/
```

审核通过的内容才会进入八大分类里的知识主文档、案例库和模板库。

这一步很重要。视频里讲得顺，不代表可以原样写进长期知识库。过时规则、平台入口、价格、账号安全、黑科技做法，都要先拦下来。
