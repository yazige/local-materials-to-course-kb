# 测试与回归

## 自动测试

项目只使用 Python 标准库：

```bash
python3 -m unittest discover -s tests -v
```

目前覆盖：

| 场景 | 验证内容 |
|---|---|
| 个人知识库初始化 | 入口文件、四个队列目录和主题目录是否创建 |
| 队列盘点 | TBD、Done、隐藏文件、两类待复核区统计 |
| 缺目录检查 | 缺少 `素材/待整理/Done` 时是否报错 |
| 结构验证 | 初始化结果、图片链接和待复核警告 |
| 自动化模板 | 三套模板是否齐全且默认暂停 |
| Skill 一等能力 | 三项能力、上下文边界、体检输出和创作写入白名单 |
| 首页 onboarding | 建库路径是否先于 Skill 安装，来源和上下文机制是否完整 |
| 上下文硬边界 | 总索引、去重顺序、转写读取边界和两阶段体检是否写入 Skill |
| 健康盘点 | 断链、完全重复、孤岛、待确认、过期和索引覆盖候选 |
| 正文防泄漏 | JSON 不得包含页面正文；大库候选列表必须有上限和截断标记 |

## 人工回归

每次大改后选 1–2 个小样例：

- 单个 Word/PDF；
- 多个同主题文档；
- 带讲者备注的 PPT；
- 视频转写资料包；
- 平台规则、费用或账号安全资料；
- 一组完整的 AI 初稿、修改意见和终稿。

通过标准：

- 原始资料没有被覆盖；
- 只处理一个合理批次；
- 有且只有一个主分类；
- 正文进入主题页，入口页保持轻量；
- 审核内容与正式知识分开；
- 索引和状态能让下一次运行直接接手；
- 自动化配置没有被意外启用或执行。
- 三份 Skill 内容一致；
- 本机三项自动化均为 `PAUSED`，路径与提示词符合职责。
- 体检先运行 `kb_health_inventory.py`，AI 只打开有界候选页。
