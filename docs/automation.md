# 三套 Codex 自动化

本项目内置三套自动化模板。完整提示词在：

```text
skills/local-materials-to-course-kb/references/automation-presets.md
```

## 安全默认值

- 新建或更新后保持 `PAUSED`；
- 只保存配置，不立即运行；
- 用户检查路径和提示词后，再手动启用；
- 每个自动化只负责一种工作。

## 1. 资料沉淀队列

作用：检查 `素材/待整理/TBD`，恢复未完成批次，或选择一个新批次沉淀。

边界：

- 每次最多处理一个批次；
- `Done` 只读；
- 完成审核、索引和验证后才归档；
- 中断时写状态，不把半成品移入 Done。

建议按资料投放节奏设置，不必高频空跑。

## 2. 本地知识库每周体检

作用：检查队列积压、断链、孤立页面、重复主题、过时内容和旧路径残留。

边界：

- 默认只读；
- 先给问题清单；
- 不自动批量修复；
- 不触发资料沉淀。

建议每周一次。

## 3. 每周创作复盘

作用：对照 AI 初稿、人工修改意见和最终稿，提炼可复用的创作规律。

边界：

- 只读 `待复核/创作复盘`；
- 材料不全时不猜测；
- 单次复盘进入 `reviews/`；
- 重复出现的稳定规律才进入 `wiki/`；
- 不读取课程资料复核区。

建议每周一次，或安排在固定创作日之后。

## 为什么默认暂停

自动化会长期运行。第一次设置时，路径写错、边界不清或目录尚未准备好，都可能造成重复处理。先保存为暂停状态，让人检查一次，比“创建后立刻跑一遍看看”更稳。

需要测试时，也应由用户明确选择一个小样例手动触发。
